# Teranga Technologies — Growth Assets (EN / FR)

Outreach templates, service packages and an SEO plan for Teranga Technologies. French versions are written natively, not translated.

## How to use this file

**Rules**

- Replace every `[BRACKET]` before sending.
- Use only the facts in this file. Do not add clients, metrics, testimonials, certifications, team size, years in business, outcomes or prices.
- Describe Radiora and EduSen by features only: no time savings, accuracy, user counts or approvals.
- Radiora: the AI assists. It never diagnoses, validates or signs. Only the radiologist validates and signs.
- Durations: always "typically" and "subject to scope".
- Words to avoid: revolutionary, cutting-edge, game-changing, unlock, leverage, transform, best, leading, world-class. Never position on price or as "offshore" labour.
- One ask per message: a short discovery call.
- One language per message. French always uses "vous".

**Claims that need owner verification before use**

1. Every duration marked `[OWNER TO CONFIRM]`. Only "MVP typically 4–8 weeks, subject to scope" is confirmed.
2. Radiora's 30-day free trial is still offered, and the listed Radiora and EduSen features are still live.
3. Permission to name XP Client Academy, SunuPermis and the Clinic Management System publicly.
4. Source-code and IP ownership terms at handover.
5. Capacity for enterprise team extension; any security or compliance claim (GDPR, data residency).
6. Who pays AI/API usage costs in pilots.
7. Sender name and role, and the call length (default: 20 minutes).

**Signature block (all emails)**

## 4. Service packages

Every package: **Pricing: set by owner — [OWNER TO DEFINE]**. Durations are typical and subject to scope.

### 4.1 Discovery & Scoping Sprint

- **For:** founders and teams with an idea, a backlog or an outdated tool, but no agreed scope.
- **Outcome:** a prioritised scope and plan that you own, ready to build.
- **Deliverables:**
  - Stakeholder interviews and user-flow mapping
  - Prioritised feature list (now / next / later)
  - Architecture outline and key technical risks
  - Milestone plan and written build estimate
- **Fit:** a decision-maker joins the workshops. **Not a fit:** scope already documented.
- **Included:** remote workshops (FR or EN), the documents above, one review round. **Excluded:** production code, full visual design.
- **Typical duration:** 1–2 weeks [OWNER TO CONFIRM].
- **Positioning:** EN "Know what to build, and in what order, before you spend on code." / FR « Sachez quoi construire, et dans quel ordre, avant d'investir dans le code. »
- **Pricing:** set by owner — [OWNER TO DEFINE]

### 4.2 SaaS MVP Build

- **For:** funded startups launching a first version or replacing a prototype with a v2.
- **Outcome:** a deployed product real users can use, on an architecture that can grow.
- **Deliverables:**
  - UX flows and UI for core screens
  - Web application (mobile if in scope)
  - Authentication, roles, per-customer data isolation
  - Admin dashboard
  - Production deployment, documentation and code handover (ownership per contract)
- **Fit:** agreed scope (or a completed Discovery Sprint); one product owner on your side. **Not a fit:** open-ended feature list; a full enterprise feature set expected in an MVP.
- **Included:** build, testing, deployment, regular demos, FR/EN interface if required. **Excluded:** marketing site, third-party licences, post-launch maintenance (see Care plan).
- **Typical duration:** 4–8 weeks, subject to scope.
- **Positioning:** EN "Your first version in users' hands within weeks, built to grow." / FR « Votre première version entre les mains de vos utilisateurs en quelques semaines, prête à évoluer. »
- **Pricing:** set by owner — [OWNER TO DEFINE]

### 4.3 AI Workflow Pilot

- **For:** operations leads and innovation teams with repetitive document, dictation or communication work.
- **Outcome:** one real workflow automated with human review, tested on your data, ending in a decision: scale, adjust or stop.
- **Deliverables:**
  - Workflow mapping and review of sample data
  - Working pilot in a simple web interface or one existing tool
  - Human review and approval step
  - Log of AI outputs and human edits
  - Pilot report: observations, risks, next steps
- **Fit:** a named process owner; 20+ real examples available. **Not a fit:** AI making final decisions unreviewed; no access to real data; an "AI everywhere" brief.
- **Included:** one workflow, FR and/or EN, model and API selection, onboarding of pilot users. **Excluded:** company-wide rollout, training models from scratch, AI usage costs ([OWNER TO DEFINE]).
- **Typical duration:** 3–6 weeks [OWNER TO CONFIRM].
- **Positioning:** EN "Practical AI on one real process, with people in control." / FR « De l'IA concrète sur un vrai processus, sous contrôle humain. »
- **Pricing:** set by owner — [OWNER TO DEFINE]

### 4.4 Web Application / Internal Tool

- **For:** SMEs and enterprise teams running key operations on spreadsheets or email threads.
- **Outcome:** one dependable tool that removes manual steps and gives managers real-time visibility.
- **Deliverables:**
  - Process mapping
  - Role-based web application (records, workflows, notifications, dashboards as scoped)
  - Data import from existing spreadsheets
  - Access logging
  - User guide and short training (FR/EN)
- **Fit:** a stable process with an owner. **Not a fit:** a process still changing weekly; a full ERP replacement.
- **Included:** build, data import, deployment, training. **Excluded:** hardware, third-party licences, integrations not listed in scope.
- **Typical duration:** 4–10 weeks [OWNER TO CONFIRM].
- **Positioning:** EN "Replace the spreadsheet your operations depend on." / FR « Remplacez le tableur dont dépendent vos opérations. »
- **Pricing:** set by owner — [OWNER TO DEFINE]

### 4.5 Website & Conversion Upgrade

- **For:** companies whose website does not explain the offer clearly or bring in enquiries.
- **Outcome:** a fast site that says what you do and makes contacting you easy.
- **Deliverables:**
  - Messaging and page structure

- **Fit:** a clear offer; one person approves content. **Not a fit:** brand identity from scratch; large e-commerce catalogue.
- **Included:** design, build, agreed revision rounds. **Excluded:** photography, paid ads, ongoing content production.
