## 6. Risks identified

1. No browser-visible reference → visitors cannot quote their request; support follow-up harder.
2. Attribution incomplete (no content/term, entry page, conversion page, channel) and printed as one free-text line → hard to report by source.
3. Event names and payloads unvalidated; a future provider would receive whatever is passed; no protection against duplicates or personal data.
4. No privacy page describing processors, storage and retention.
5. No explicit request-size limit in the function.
6. Lead counts exist only as emails; no repeatable report.

## 7. Implementation decisions

1. **Keep the architecture.** Static generation, one function, Resend. No framework, database, CRM or new dependency.
2. **Analytics provider: Vercel Web Analytics (cookieless), behind build-time switches** in `site/config.mjs`: `webAnalytics` adds the official script to every page; `customEvents` forwards events to `va()` (Pro only, max properties configurable). Shipped with `webAnalytics: true`, `customEvents: false`; enabling Web Analytics in the Vercel dashboard is a release gate for the owner.
3. **One event module in `main.js`**: the eight approved events, each with an allow-list of properties and value patterns; unknown events and properties dropped; values limited to short identifiers; repeated identical events within 1 s ignored; failures swallowed. Events always reach an in-page bus (`tt:analytics` DOM event + `window.TT.events`) for UAT and tests.
4. **Server-side lead records are the source of truth**: an inquiry counts only when Resend accepted its notification (unchanged contract). Each notification carries the reference, validated attribution and a tab-separated tracker row.
5. **Attribution**: add `utm_content`, `utm_term`, entry page, conversion page and a server-computed channel (`campaign` / `referral` / `direct`); session-only storage; every field re-validated on the server.
6. **Confirmation**: the API returns the reference; the form shows a localized confirmation panel with it, focus moved to it, and a "send another request" action.
7. **Owner reporting**: a private spreadsheet tracker (template + statuses) and a dependency-free `scripts/lead-report.mjs` that computes the metrics from its CSV export; synthetic sample only.
8. **Privacy**: new `/privacy` and `/fr/privacy` pages (footer and form links) describing data, processors, storage, retention and rights — without legal claims.
9. **Budget field: not added.** Currency and ranges are still an owner decision (open since TERANGA-01); an optional field can follow once chosen.
10. **Fix the start-up layout thrash** (batch reads before writes, defer to the next frame).
